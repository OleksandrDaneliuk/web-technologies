Блок «Прокручування фону» (background-attachment)

background-attachment: scroll

Веб-розробка — це процес створення веб-сайтів або веб-додатків. Цей довгий блок тексту створений для демонстрації поведінки прокручування. При прокручуванні тексту усередині цього блоку фон залишається нерухомим відносно меж контейнера. Текст рухається перед фіксованим фоном. Продовження тексту для появи смуги прокручування: тестування роботи властивості scroll у блоці з обмеженою максимальною висотою.

background-attachment: local

Веб-розробка — це процес створення веб-сайтів або веб-додатків. Цей довгий блок тексту створений для демонстрації поведінки прокручування. При прокручуванні тексту усередині цього блоку фон рухається разом із текстом, оскільки він прив'язаний безпосередньо до вмісту (контенту) елемента. Продовження тексту для появи смуги прокручування: тестування роботи властивості local у блоці з обмеженою максимальною висотою.
